## 🧱 Blocages et solutions
- `permission denied … docker.sock` → `equipe` ajouté au groupe `docker`, puis reconnexion SSH
- Copier-coller de blocs `<<'EOF'` dans le SSH : des espaces avant `EOF` bloquent le shell, puis coupure SSH → fichiers écrits sur un laptop et passés par Git
- `git push` refusé depuis le serveur (mot de passe GitHub) → commit rapatrié sur un laptop avec `git fetch ssh://…` puis poussé de là ; pas de token sur le compte partagé
- PR #4 en conflit après le squash de la PR #1 → branche reconstruite sur `main` + `cherry-pick` du seul commit `server/`
- `curl 192.168.137.1:8000` sans réponse → relais `netsh portproxy` vers `127.0.0.1` + règles de pare-feu Windows
- C270 invisible dans WSL → `usbipd attach --wsl --busid 6-3` (4-1 = webcam intégrée)
- Python d'Ubuntu 26.04 trop récent pour `numpy < 2.3` → `.venv` en Python 3.12 via `uv`
- Caméra ouverte mais aucune trame avec **OpenCV 5.0** → `opencv-python<5` (correctif `requirements.txt` à fusionner)
